# Reign banner art

- `reign-logo.txt` — "REIGN" in ANSI Shadow (pyfiglet), 6 lines x 38 cols. Replaces the 101-col HERMES-AGENT block.
- `rook-hero.txt` — the Rook outline mark rendered to braille, 15 lines x 30 cols. Replaces the caduceus hero.

Both are plain text; each surface applies its own colors. Rook palette is monochrome:
dark terminals use white -> silver -> grey (#FFFFFF, #C0C0C0, #8A8A8A, #5C5C5C);
light terminals use black -> charcoal -> grey (#000000, #333333, #6B6B6B, #9A9A9A).
